yb.audio_convert¶

Convert audio files between formats with ffmpeg.

Audio arrives in whatever format the source offers — YouTube’s best audio is typically Opus in a .webm container — which is usually fine to keep as is. Publishing paths, though, often want something specific: .mp3 for podcast players, .wav for editing. convert_audio() is the one-call bridge:

>>> from yb.audio_convert import convert_audio
>>> convert_audio("talk.webm", "mp3")
PosixPath('talk.mp3')

Conversion is a no-op when the source is already in the target format, so it is safe to call unconditionally:

>>> convert_audio("talk.mp3", "mp3")
PosixPath('talk.mp3')

Requires ffmpeg on PATH; without it AudioConversionError is raised (see also the on_error="warn" escape hatch in yb.download.download_youtube_audio()).

yb.audio_convert.convert_audio(src, audio_format, *, output=None, bitrate=None, overwrite=True, extra_ffmpeg_args=())[source]¶

Convert src to audio_format, returning the resulting path.

Parameters:

  • src (str | Path) – The audio file to convert.

  • audio_format (str) – Target format as an extension ("mp3", ".wav", …).

  • output (str | Path | None) – Destination path. Defaults to src with the new extension.

  • bitrate (str | None) – Target bitrate for lossy formats (e.g. "320k"). Defaults to DEFAULT_LOSSY_BITRATE; ignored for LOSSLESS_FORMATS.

  • overwrite (bool) – Overwrite output if it already exists.

  • extra_ffmpeg_args (Iterable[str]) – Raw ffmpeg arguments, appended last so they win.

Return type:

Path

Returns:

The converted file’s path — or src unchanged when it is already in the target format (no pointless re-encode, no generation loss).

Raises:

  • FileNotFoundError – If src does not exist.

  • AudioConversionError – If ffmpeg is missing, or the conversion fails.

yb.audio_convert.normalize_format(audio_format)[source]¶

Normalize a format spec to a bare lowercase extension.

Accepts it with or without the leading dot, in any case:

>>> normalize_format("mp3"), normalize_format(".MP3"), normalize_format(" .Wav ")
('mp3', 'mp3', 'wav')
Return type:

str
