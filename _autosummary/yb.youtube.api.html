yb.youtube.api¶

YouTube video operations: get, upload, update metadata, thumbnail, chapters.

These wrap the YouTube Data API v3 videos/thumbnails resources for both creating videos and editing already-published ones (titles, descriptions, tags, languages, and chapter blocks in the description).

yb.youtube.api.supersede(old_id, new_id, *, old_privacy='private', new_privacy=None, move_playlists=True, service=None, **cred_kwargs)[source]¶

Retire an upload that new_id replaces (yb#19).

YouTube cannot replace a video’s file, so a re-cut is a new upload. This puts the new one where the old one was and takes the old one out of view:

  1. refuses, before changing anything, unless new_id has finished processing (uploadStatus == "processed"): retiring the old video for a failed or rejected upload would leave the public neither;

  2. sets new_id to new_privacy when given (e.g. "public");

  3. for every playlist of yours that holds old_id (when move_playlists): inserts new_id at the old one’s position (or appends, if the playlist is not sorted manually), THEN removes old_id, so a failure part-way never leaves a playlist with neither;

  4. sets old_id to old_privacy (default "private"), clearing any scheduled publish. It is never deleted.

The new video keeps its own privacy unless new_privacy is given, and an upload is unlisted by default: so the re-cut of a public video is NOT made public for you. When the result is less visible than the old video was (a public original, an unlisted re-cut), a VisibilityDropWarning is emitted before anything changes; pass new_privacy="public" to publish the re-cut, or turn the warning into an error to refuse such calls.

Captions and thumbnails are not copied: upload them with the new video (yb.youtube.publish_video()). Safe to re-run: every step checks before it acts. Quota: see yb.youtube.playlists_containing(); each write (insert, delete, update) is 50 units.

Return type:

dict

Returns:

{"old_id", "new_id", "playlists", "old_privacy", "new_privacy"} where playlists lists {"playlist_id", "added_new", "position", "removed_old"}.

yb.youtube.api.update_video_status(video_id, *, privacy_status=None, contains_synthetic_media=None, keep_schedule=False, service=None, **cred_kwargs)[source]¶

Change a video’s privacy (or synthetic-media flag), keeping the rest.

Read-modify-write of the status part (yb#19): videos.update replaces the part wholesale, so the current writable fields are carried over and only the ones given change. Making a video private never deletes it.

Setting privacy_status clears a scheduled publish (publishAt): otherwise a video made private while scheduled would still go public at that time, and a past publishAt read back is refused by the API. Pass keep_schedule=True to keep it (only meaningful with "private").

Raises:

ValueError – privacy_status is not one of PRIVACY_STATUSES.

Return type:

dict
