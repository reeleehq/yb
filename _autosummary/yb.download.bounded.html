yb.download.bounded¶

Link-to-audio with the safety policy applied once: download_audio_bounded().

A service that turns a user-supplied link into an audio file (an MCP tool, an ingest endpoint) needs the same guard rails every time: refuse bad targets before touching the network, refuse over-long sources before fetching a byte, cap the download size, always produce mp3, and carry a copyright notice with the file. That policy lives here so a second consumer does not copy it.

The caps are keyword-only arguments, and they are written after any caller extra_opts, so a configured yt-dlp option (credentials, cookies, proxies) can never widen them.

>>> from yb.download import download_audio_bounded
>>> got = download_audio_bounded(url, max_bytes=60 * 2**20, max_duration_s=45 * 60)
>>> got.path, got.title, got.duration_s, got.notice

yb.download.bounded.download_audio_bounded(url, *, download_dir, max_bytes=83886080, max_duration_s=2700, validate_target=<function require_http_url>, extra_opts=None, cookies_file=None, notice="Downloaded from a user-supplied link — respect the source's copyright and terms of service; you are responsible for having the right to use it.")[source]¶

Download the audio of one video link as mp3, refusing what exceeds the caps.

Order: validate_target on url (before any network), a metadata-only fetch that refuses playlists, live streams and over-long sources (before any media bytes) and re-validates the resolved page URL, then the download with the caps pinned, then a size check on the extracted file. The mp3 is written to a fresh private directory under download_dir (so concurrent calls never collide); on any failure that directory is removed.

Parameters:

  • url (str) – A page link (YouTube, SoundCloud, Bandcamp, …).

  • download_dir (str | Path) – Parent of the per-call directory holding the mp3 (the caller owns that directory from then on and removes it after ingest).

  • max_bytes (int) – Cap on the downloaded and on the extracted file.

  • max_duration_s (float) – Cap on the source’s duration. A source that reports no duration passes this check and is bounded by max_bytes alone.

  • validate_target (Callable[[str], None]) – Raises ValueError to refuse a URL; see require_http_url(). Not an egress sandbox: yt-dlp follows redirects itself.

  • extra_opts (Mapping[str, Any] | None) – Deployment yt-dlp options, restricted to DEPLOYMENT_OPT_KEYS (credentials, cookies, proxy); anything else raises, so no option can widen a cap or redirect the output.

  • cookies_file (Union[str, Path, Literal[False], None]) – As in download_youtube_video().

  • notice (str) – Copyright notice returned in the result.

Raises:

  • ValueError – validate_target refused a URL, a cap is not positive, or extra_opts has a key outside DEPLOYMENT_OPT_KEYS.

  • AudioLimitError – Playlist, live stream, too long, or too large.

Return type:

AudioDownload

yb.download.bounded.require_http_url(url)[source]¶

Default target check: an http(s) URL with a host.

This is only the floor. A service fetching on behalf of untrusted callers should pass a validate_target that also refuses loopback, private, link-local and cloud-metadata hosts.
